Which voice should take over when Supertonic can't?

Each letter is one candidate voice, and the letter is the same in every passage. The order is shuffled per passage. Every clip is matched for loudness, so a louder voice has no advantage.

  1. Use headphones and listen to every letter in each passage.
  2. Rate each clip 1–5: 1 = I'd stop listening, 3 = fine for a while, 5 = as good as a person reading.
  3. At the bottom, answer "Acceptable as the fallback?" for each letter and add notes if you like.
  4. Tap Save ratings. The agent reads them from this page. The answer key is in a separate file; don't open it until you've saved.

Your verdict

Average of your three ratings per letter. Answer yes or no for each one.
