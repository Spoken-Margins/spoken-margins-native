# Quick start

This page gets you from nothing to a running server.

## Install

Download the release for your system and put it on your path.

## Create a project

Run the init command in an empty folder. It writes a config file.

## Start the server

Run the serve command. The default port is 8080.

## Open the dashboard

Visit the address the server prints.

## Add your first route

Edit the config file and add a path and a handler name.

## Reload

Save the file. The server picks up the change.

## Troubleshooting

If the port is busy, pass a different one with the port flag.
