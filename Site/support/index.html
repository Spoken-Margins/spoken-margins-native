Beta Support

Found a rough edge? A concise report with the privacy-safe diagnostics is the fastest route to a fix.

Send a report

Email resists.fabric-0o@icloud.com with what you expected, what happened, your device model and iOS version, and whether you can reproduce it.

Copy diagnostics

In Spoken Margins, open Settings → Support & Privacy → Copy Privacy-Safe Diagnostics, then paste the result into your email. Review it before sending. It omits source content, transcripts, API keys, and recorded audio.

Reset during beta

Deleting and reinstalling the TestFlight build clears the app library. The OpenAI API key may remain in Keychain until you choose Delete API Key in Settings or remove it from the device’s credentials.

Optional live AI

Live AI features require an OpenAI API key supplied by the tester and explicit consent before source or conversation text is sent. Import, listening, navigation, interjections, sharing, and export remain available without an API key.

Known beta boundaries

Lock-screen and Live Activity controls, microphone capture, the Share extension, and the Safari extension depend on device and system integration. Include the affected device and extension state in any report. This beta does not include a watchOS app.
