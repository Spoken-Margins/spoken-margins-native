Open a shared margin.

A .spokenmargins file carries a friend’s reviewed commentary and source anchors. It does not carry the podcast or article itself.

Join the TestFlight beta

If Spoken Margins is installed

  1. Tap the .spokenmargins attachment.
  2. Choose Open in Spoken Margins when iOS asks.
  3. For an article, let the publisher page load visibly, then choose Create Item & Add Shared Interjections. A matched podcast is added immediately without autoplaying or downloading.

What you will hear

Shared commentary starts in Companion mode. A double tone and “Interjection 1 of 3” offer a Listen action; ignoring it continues the source. While commentary plays, Return to Source takes you back to the saved source position.

Privacy and source material

The package may include a sender label, approved transcripts, deterministically cleaned commentary audio, short anchor excerpts, and source-identification details. It excludes raw captures, complete source text, source audio, diagnostics, filesystem paths, API data, and unrelated turns. An integrity check detects modification, but it does not authenticate the sender.

If the article cannot be read

Choose Retry first. If extraction still fails, choose Open in Safari & Send to Spoken Margins, then use Safari’s Share button to send the visible page back to Spoken Margins. The app retains the pending package so the return does not create a duplicate.

If tapping the attachment does nothing, install the current beta and try again. The attachment itself cannot redirect to TestFlight when the app is absent.
