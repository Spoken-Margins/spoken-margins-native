Spoken Margins

Privacy Policy

Effective July 19, 2026 · Beta version 0.1

Spoken Margins keeps your library, recordings, transcripts, conversations, and settings on your device unless you deliberately use a feature that sends text to OpenAI.

What stays on your device

Imported text, saved links, listening maps, playback history, interjection audio and transcripts, exports, settings, and the OpenAI API key you provide are stored locally. The API key is stored in the Apple Keychain. Spoken Margins has no developer-operated account system, analytics, advertising, or tracking service.

Live AI requests

Before the first live AI request, the app asks for consent. If you allow it, the request may include source excerpts needed for the task, interjection transcripts, your current follow-up, nearby text anchors, and recent conversation text. It does not include recorded audio, local file paths, or internal database identifiers. You can revoke consent and delete the API key in Settings.

Requests go directly from your device to the OpenAI API using the API key you supply. Spoken Margins sets the Responses API store option to false. OpenAI states that API inputs and outputs are not used for model training by default; its standard abuse-monitoring logs may retain customer content for up to 30 days. Your OpenAI organization’s own data-control settings also apply. See OpenAI’s API data controls.

Apple services

If you enable speech transcription or use system voices, Apple’s operating-system services may process audio or text under Apple’s terms and your device settings. Spoken Margins does not operate a server for that processing.

Sharing and browser extensions

The Share extension and Safari extension write only the item you explicitly share or capture into the app’s private shared container. The Safari extension runs only when you invoke it; it does not continuously read browsing activity.

Deletion and retention

You can move library items to Recently Deleted, permanently delete them in the app, delete your API key in Settings, or remove the app to remove its local app data. An upgrade from an earlier private beta may archive the old local test database before creating the current database; the app reports the archive location in its privacy-safe diagnostics.
