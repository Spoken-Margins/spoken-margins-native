The sharing loop, end to end

Read from flow-map.json beside this file. Each screen shows the capture of the real thing named on the map, the commit it was taken at, and whether that step worked in the run. Taps are counted per person with the map's rules (a tap is 1; a menu item, context menu, swipe or VoiceOver action is 2).

Open it with python3 -m http.server -d Design/flow-map 8765, then http://localhost:8765/viewer.html; a browser won't read the map from a file:// page, so it offers a file picker instead.
