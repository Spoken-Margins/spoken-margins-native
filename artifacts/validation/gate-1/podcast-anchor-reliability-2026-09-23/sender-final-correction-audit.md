# Sender final correction audit

**Bounded ASR failure independence is present; one shared-acquisition issue remains.** No implementation or test changes were made.

- **P2 — Successful source acquisition is discarded before ASR, causing a second source-window fetch.** In `scheduleSourceWindowContextIfNeeded`, the acoustic consumer derives references from `acquisition.localAudioURL` and then removes its parent directory at `Gate1AppModel.swift:13119`; bounded ASR subsequently receives the original URL at `:13123–13130`. The production adapter uses the same `SourceAudioTranscriptionWindows/<item>/window-<anchor>-v3/source-window.m4a` path for acquisition and transcription (`AudioAdapters.swift:3457–3462`, `3513–3520`), so after deletion a remote source is loaded/exported again. Besides duplicate network work, an ad-changing URL can yield fingerprint and transcript windows from different editions. Keep the acquired window until both consumers finish and let ASR consume that window with its source-time offset; when acquisition fails, retain the current independent bounded-transcription attempt.
- **ASR still runs after acquisition failure.** Acquisition is `try?`; after it returns nil, execution continues to `transcribeSourceAudioWindow` (`Gate1AppModel.swift:13074–13130`). `testNativeAudioInterjectionRequestsFullShoulderContext` uses a test client without a local acquisition artifact and reaches `complete:speech_window`, exercising the fallback. A dedicated injected acquisition throw/count assertion would make that independence less implicit, but the current path is sound.
- **The DEBUG fixture helper traverses the real export refresh, but does not test stale-versus-current values.** `persistSelectedInterjectionsForSharingTests` seeds SQLite (`Gate1AppModel.swift:14578–14582`); the sharing coordinator then calls production `exportSharedInterjections` (`Build23SharingSeams.swift:535–546`), whose `refreshedIncludedShareDrafts` reloads each active row by session, id, and item (`Gate1AppModel.swift:14562–14575`). This is not an export bypass. Existing fixtures mirror in-memory drafts, however, so they do not prove a changed persisted row overrides or rejects a stale reviewed draft. Add one bounded mutation-after-review test if that strict freshness guarantee needs regression protection.
