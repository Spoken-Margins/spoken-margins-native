# D/E/F app integration audit

Read-only audit of the current `codex/co-op` worktree and the September 23 brief. No code, schema, or test changes were made; no tests or builds were run.

## Priority findings

1. **D — decouple source-window acquisition from both consumers.** `Gate1AppModel.scheduleSourceWindowContextIfNeeded` ([Gate1AppModel.swift:13005](../../../../App/SpokenMarginsApp/Sources/SpokenMarginsApp/Gate1AppModel.swift#L13005)) returns as soon as it finds a stored transcript window. When decoded/exact capture failed, this also skips the source-window acoustic fallback. Its remote/local path calls `SourceTranscriptionClient.transcribeSourceAudioWindowWithEvidence` ([Protocols.swift:202](../../../../Packages/SessionKit/Sources/SessionKit/Protocols.swift#L202), [AudioAdapters.swift:3502](../../../../Packages/SessionKit/Sources/SessionKitAudio/AudioAdapters.swift#L3502)); the implementation exposes the extracted file only after ASR succeeds. An ASR error therefore prevents fingerprinting the already-acquired audio. Add one acquisition result carrying interval, source edition/provenance, and a temporary local URL; run fingerprinting and ASR as independent consumers, serializing only where the speech service requires it. A stored transcript should satisfy text context while leaving any missing acoustic flank scheduled. Keep refetched/downloaded-reference signatures labeled as reference evidence and never convert their source timestamp directly into sender-edition placement.

2. **B/C state now has a core shape, but the app does not consume it.** The current dirty core defines per-window state on `Interjection.podcastAnchorCaptureWindows` ([Models.swift:1295](../../../../Packages/SessionKit/Sources/SessionKit/Models.swift#L1295)) and transition helpers, and the SQLite reopen round-trip is covered in [SQLiteSessionStoreSafetyTests.swift:21](../../../../Packages/SessionKit/Tests/SessionKitTests/SQLiteSessionStoreSafetyTests.swift#L21). `Gate1AppModel` still persists through its older aggregate helpers ([Gate1AppModel.swift:13488](../../../../App/SpokenMarginsApp/Sources/SpokenMarginsApp/Gate1AppModel.swift#L13488)); there are no app references to `podcastAnchorCaptureWindows`. Its `persistPodcastAnchorEvidence` also assigns the optional edition digest unconditionally, so a source-window result with `nil` erases a previously known exact-edition hash, while any one successful role sets the aggregate status to `.ready`. Route callbacks through the core transition API, preserve a known digest when an update has none, and derive readiness per role rather than from any nonempty evidence array.

   Add an app-start/foreground reconciliation entry point that loads durable jobs across sessions, validates committed files and digests, repairs orphan-file/DB-commit gaps, and resumes only retryable work whose item, interval, and edition still match. Current `retrySourceWindowContexts` ([Gate1AppModel.swift:13156](../../../../App/SpokenMarginsApp/Sources/SpokenMarginsApp/Gate1AppModel.swift#L13156)) is called after transcript attachment and podcast-download readiness, not as durable capture-job reconciliation. Carry an attempt/generation token through worker callbacks so a late result cannot replace a newer retry, item edition, or deleted Margin. Session-qualified Margin identity already exists at `Gate1AppModel.swift:7647`; retain it and add the attempt/edition identity.

3. **E — refresh export from a consistent durable snapshot and make degradation a recorded choice.** `prepareShareInterjections` copies the supplied `Interjection` values into in-memory drafts ([Gate1AppModel.swift:13580](../../../../App/SpokenMarginsApp/Sources/SpokenMarginsApp/Gate1AppModel.swift#L13580)); `refreshSelectedItem` refreshes the item but not those drafts ([Gate1AppModel.swift:15258](../../../../App/SpokenMarginsApp/Sources/SpokenMarginsApp/Gate1AppModel.swift#L15258)). Export then reads evidence from `draft.interjection` and filters missing files out with `fileExists` ([Gate1AppModel.swift:14203](../../../../App/SpokenMarginsApp/Sources/SpokenMarginsApp/Gate1AppModel.swift#L14203)), so newly committed evidence can be absent from an already-open draft and a disappeared file can be silently omitted. Reload the selected Margins and evidence at export, pin and validate the exact files/digests through archive assembly, and return a typed pending/unavailable/missing/corrupt outcome. If automatic-positioning evidence is degraded, add the brief’s one-time “keep preparing” / “share now without automatic positioning assurance” decision. The existing “Include acoustic evidence” toggle ([Build23SenderSharingExperience.swift:287](../../../../App/SpokenMarginsApp/Sources/SpokenMarginsApp/Build23SenderSharingExperience.swift#L287)) is an intentional inclusion preference and must remain distinguishable from capture failure.

   Current package anchors transport only `machineEvidenceAssetIds` ([SharingModels.swift:262](../../../../Packages/SessionKit/Sources/SessionKit/SharingModels.swift#L262)); the package schema is [shared-commentary-layer.schema.json](../../../../Contracts/schemas/shared-commentary-layer.schema.json#L30). Add an optional, versioned per-Margin outcome/provenance summary there (including intentional omission versus unavailable/pending); absence on older packages must decode as unknown legacy state. Keep device paths, full transcripts, and diagnostics private. Update the schema, `InterjectionPackageArchive` validation, contract fixtures, and archive tests in the same change, per `AGENTS.md` specification discipline.

4. **F — bound recipient ASR, bind it to bytes, and expose explicit confirmation.** When any imported Margin remains unresolved, `resolveImportedPodcastCommentary` ([Gate1AppModel.swift:16615](../../../../App/SpokenMarginsApp/Sources/SpokenMarginsApp/Gate1AppModel.swift#L16615)) schedules `scheduleTransientRecipientAlignmentTranscript`, which transcribes the full recipient source ([Gate1AppModel.swift:16554](../../../../App/SpokenMarginsApp/Sources/SpokenMarginsApp/Gate1AppModel.swift#L16554)). The resulting timeline is passed without an edition digest; the callback checks URL equality, which does not prove the file bytes stayed the same. Add bounded candidate-centered windows (sender time is only a hint), one widening pass, fair/coalesced work, and digest + generation checks before caching or committing. `PodcastTranscriptAnchorResolver.resolve` ([PodcastAnchorEvidence.swift:641](../../../../Packages/SessionKit/Sources/SessionKitAudio/PodcastAnchorEvidence.swift#L641)) proves uniqueness only within the timeline it receives: a hit unique in a small window must stay provisional until global/expanded search rules establish uniqueness.

   The imported-Margin card already offers direct voice playback regardless of placement ([Build23ImportedMarginPresentation.swift:276](../../../../App/SpokenMarginsApp/Sources/SpokenMarginsApp/Build23ImportedMarginPresentation.swift#L276)). `recipientConfirmed` already exists in the resolution model and label, but there is no app confirmation command or mutator. Add a listen-around-proposal / confirm action that stores the recipient-edition digest and a `recipientConfirmed` result, clearly distinct from acoustic/transcript verification. Preserve the current partial-flank guard (`PodcastAnchorEvidence.swift:521`) and tests (`SharingTests.swift:680`); do not promote a single post-only match by subtracting its sender offset across an edition change.

## Product-contract check and focused coverage

The new scope is correctly routed to the existing `codex/co-op` lane (`docs/release-lanes.md:1,144`) and aligns with its explicit quick-share/degraded-choice direction. The brief should state one inherited requirement more directly: the September 1 release contract requires bounded sender source ASR whenever source audio is available, even when signatures are ready, and requires bounded transcript context in each reviewed share (`docs/release-lanes.md:268`). Packet D should say that fingerprint success cannot skip this ASR obligation. The brief otherwise preserves the stronger #27 acceptance gate: zero false-confident placements and p95 error ≤1.5 s (`docs/release-lanes.md:259`); its device capture/commit targets are additional engineering measures, not a replacement. The old-package playback requirement is already represented by the direct Listen action and should remain true for legacy packages with no evidence summary.

Useful existing seams and tests: `SourceLinkImportTests.testNativeAudioInterjectionRequestsFullShoulderContext` and `testInterjectionTranscriptionFinishesBeforeSourceWindowTranscriptionStarts` exercise sender context and ASR serialization; add forced-ASR-failure-with-fingerprint, stored-transcript-with-acoustic-pending, one-shared-acquisition, edition-change/stale-callback, and relaunch reconciliation cases. `SharingTests` already covers acoustic/transcript ambiguity, partial-flank corroboration, and old evidence decoding; extend app/archive coverage for fresh evidence entering an open draft, file deletion/corruption during export, explicit degraded consent versus opt-out, versioned failure summaries, and old-package forwarding. `SpokenMarginsPackageHandoffTests` currently checks transient full-transcript cleanup and recipient transcript resolution; add bounded/global-uniqueness and recipient confirmation persistence/UI cases, including a repeated phrase outside the initial local window.
