# Build 27 — proposed internal TestFlight notes

This build brings the second-edition Library, Following and Margins experience, including written Margins, together with playback and sharing fixes.

Please update in place and keep your existing Library. Check that your items, listening positions, recordings, written Margins and imported collections are still present.

- Listen to a shared voiced Margin over a podcast or text source. Pause and resume using the main player and system controls. The source should remain paused until you return to it or the Margin finishes.
- Try Skim, then confirm ordinary source playback resumes and continues advancing.
- Paste a long assistant response in Timeline. The import action should stay reachable above the editor and start playback. Add Margins at several points; each should remain under the correct response after reopening the app.
- Open a newly added text item while audio is preparing. You should still be able to start listening.
- Review a share preview, including outgoing excerpts, voice representations and matching evidence. Turning off acoustic evidence should omit those acoustic signatures. Importing a package should not start playback automatically.
- Try the updated Library, Following, Margins, written capture, storage and sharing screens on your normal device, including larger text and dark appearance.

Sharing remains a deliberate file export: review what you send and share only material you have permission or another lawful basis to share. Recipients can retain or forward a copy.

For a problem, include Build 27, device/OS, the steps and what you heard or saw. Settings → Copy Privacy-Safe Diagnostics can help. Do not reset your personal Library to reproduce a problem.

These notes are prepared locally. They have not been posted to App Store Connect.
