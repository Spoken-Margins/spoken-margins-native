# Build 19 App Store Connect iPhone screenshots

These images are the App Store product-page set for issue #41. They are not
required for external TestFlight review.

Source captures: `../10Aug26-ScreenShots/`

The source captures are 1206 x 2622 pixels, which App Store Connect rejects for
the selected 6.5-inch iPhone screenshot slot. Each candidate was center-cropped
by 13 vertical pixels and scaled to 1284 x 2778 pixels in sRGB/RGB, one of the
exact sizes accepted by that slot.

Suggested order:

1. `01-library.png`
2. `02-item-and-map.png`
3. `03-listening-session.png`
4. `04-share-session.png`
5. `05-add-source.png`

The transformed candidates were visually checked after conversion. The matching
iPad set is in `../build-19-ipad-pro-13-2064x2752/`.

Uploaded to App Store Connect on August 21, 2026 in the iPhone 6.5-inch Display
slot. App Store Connect accepted all five images and shows `5 of 10 Screenshots`
in the order above.
